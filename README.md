# 💌 do_you_wanna_go_out_with_me?

A cute and simple HTML + CSS + JS website I made just for fun (or maybe... to pop a question 😉).

This mini-project features a soft pink aesthetic, adorable visuals, and a heart-melting message asking the age-old question:  
**"Do you wanna go out with me?"**

## 🌸 Features
- Fully responsive design
- Minimalist layout
- Cute animated cat image
- Clean code with only HTML and CSS (no JavaScript used)
